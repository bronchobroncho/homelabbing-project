# homelabbing-project
This Github repository documents my homelabbing journey, building up a server rack from the base components,
to a functioning (and hopefully well polished) home networking solution.

My current budget as of writing this (11/25/26) is ~$500 USD

The plan:

Create a completely self sufficient, and well structured, home network, built on top of an old second-hand office PC.
it needs to be:
- compact enough to fit on a shelf, or in a small nook beside my desk
- have enough space to accommodate all

Purpose for this Project:

I have decided to start this project, as it has been an idea that has laid dormant in the back of my head for YEARS now,
practically BEGGING to be brought to fruition and i finally feel comfortable enough with my technological knowledge,
and i feel that it is at a level where i can begin to understand some of the basic concepts of networking and cybersecurity
that are needed if i intend on going into the field of networking/cybersecurity (which at the time of writing is my current 
future career plan).
